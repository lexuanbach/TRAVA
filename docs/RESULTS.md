## Additional cached results

The following independent analyses are included as reference results and implementation code, but are not recomputed by the 24-stage full runner: `results/loo_control.json` (leave-one-out control), `joint_slope.json` (joint capability trend), `multilevel_capability.json` (capability regression), `fullscale.json` (uncapped panel), `controlled_cutoff.json` (same-family comparison), and `heldout_future.json` (future held-out questions). Their original entry points are under `pipeline/`; inspect `--help` and the result metadata before running them. Some original scripts combine retrieval or generation with analysis.

## Reading uncertainty

Report both the estimate and its interval from the same weighting/conditioning field. `question_pooled` and `quiz_weighted` are different estimands. `old_fulltext` and `new_visible600` are different label conditions. A nonzero-interval marker is not automatically Holm-adjusted significance.

`results/human_metric_audit.json` is the common-basis metric-error summary. `results/human_validation.json` retains the earlier report and should not be used to replace the common-basis intervals. `results/masked_human_support.json` distinguishes the 200-question weighted population estimate from 210-question unweighted interactions.

## Common-sample reporting checks

`results/reporting_summary.json` records nearest-option accuracy on the fixed 878-question sample for eleven closed-book and ten unmasked-Hybrid generators. It retains numerators, denominators, detected abstentions and unmatched answers for each condition and temporal slice. Its scale comparison aligns both metrics on the same seven-rung, quiz-weighted 2023/2026 contrast. It also reports the frozen 1.5B masking interval, using the original quiz-bootstrap seed and ordering. Recompute with `python pipeline/reporting_summary.py`.

`results/choice_grounded_audit.json` separately provides the explicit eleven-generator closed-book sensitivity, including per-model 2023/2026 intervals. Recompute with `python pipeline/choice_grounded_audit.py`.

`docs/model_inventory.json` records verified cache coverage and retained generation settings. Missing historical revisions are explicit nulls. Rebuild it with `python scripts/build_model_inventory.py`. `docs/protocols/` and `docs/corrections.md` document chronology and retrospective corrections. The corrected ledger resolves every provenance path within this repository and is checked with `python pipeline/rebuild_ledger.py --check`.

## Aligned temporal comparisons

The [estimand guide](reporting_estimands.md) defines the retrospective reporting extension. `results/aligned_contrasts.json` compares both temporal splits with common questions, two endpoints, two weighting schemes and seven-rung or six-Qwen model panels. It also provides the mean across eight half-year boundaries. `results/reporting_checks.json` records the matched exposure counts, stale-index link audit, policy-fold check and Haiku unmasked-NLI extension. Run the matching `pipeline/aligned_contrasts.py` and `pipeline/reporting_checks.py` entry points, or use the full runner. Historical summaries remain available with their original scope.

### Paired support-label comparison

`python pipeline/paired_label_comparison.py` recomputes agreement differences from the existing adjudicated labels and cached NLI/judge outputs. `results/paired_label_comparison.json` includes input hashes, row and quiz counts, seeds, paired 95% intervals, plus-one tail probabilities and within-pack Holm corrections. Passage rows have unit weights. This differs from population-weighted correctness agreement in `human_metric_audit.json`.

`python pipeline/controlled_cutoff.py` reports the exact permutation resolution from the actual size spacing. `results/controlled_cutoff.json` preserves historical numeric fields and corrects their interpretation. Both commands are included in the full cached replay.
